# Aquastat dataset from FAO

source: http://www.fao.org/nr/water/aquastat/data/query/index.html?lang=en

## download source data

1. go to https://data.apps.fao.org/aquastat/?lang=en
2. choose Share/Download
3. select Bulk download -> AQUASTAT Statistics Bulk Download - English
